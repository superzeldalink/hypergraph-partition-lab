The method

FM and KL partitioning

Both heuristics split a netlist into two blocks while cutting as few nets as possible. FM moves one cell at a time; KL swaps one cell from each block.

1 · Start balanced

Cells begin in two blocks. FM permits each block to grow to ceil(n/2) + slack cells, so a single-cell move can temporarily trade balance for a better cut. KL swaps preserve the starting block sizes.

2 · Critical nets

A net is critical when moving one of its cells can change whether the net is cut: A=0, A=1, B=0, or B=1. Cut-critical nets are cut with one cell on a side; moving that lone cell uncuts it (FS). Uncut-critical nets are internal; moving a cell cuts them (TE). A 2/2 cut net is not critical.

3 · FM: move the best cell

For cell v, gain(v) = FS(v) − TE(v). Choose the highest-gain eligible cell, move it across, and lock it for the rest of the pass. Locking lets FM climb out of local minima without immediately undoing a move.

4 · KL: swap the best pair

For a free cell v, D(v) = Eother(v) − Esame(v). Pick a free pair with the largest g(a,b) = D(a) + D(b) − 2c(a,b), swap both cells, and lock both. On this hypergraph board, the pair gain is the exact net-cut change; for two-terminal nets it equals the slide formula.

5 · Update and keep the best prefix

Only cells incident to a changed net need updated scores. Record the prefix with the lowest cut. At pass end, roll back later moves/swaps, unlock every cell, and start another pass only if the cut improved. Stop when a pass has no improvement.

6 · Read the board

Coral lines cross the cut; muted lines stay inside a block. Every net name is visible. Amber names are critical (cut-critical or uncut-critical); steel-blue names are noncritical. Select a cell for its incident-net A/B counts and the exact reason; in the editor, click a net line to inspect it directly. The pulsing cell(s) show the next FM move or KL pair. Green and red badges show gain or D(v).

7 · Switch algorithms

Use the KL / FM switch in Run control. FM is the move-based hypergraph solver; KL is the pair-swap graph algorithm applied to the same nets. The cut readout is the same unit-cost net cut for both, and the graph, editor, balance strip, and critical-net inspector are shared.

8 · Edit the graph

Edit graph turns the board into an editor. Drag cells to arrange or move them across the cut, double-click to rename, click Add cell then the board to create one, and use Connect to build nets. Pick two or more cells, then press Enter or click Create net. Connect stays active so you can build the next net; press Esc when finished. Select a net line to inspect or delete it. Clear wipes the board for a fresh start; Undo restores it.

Step = one FM move / KL swap (or one pass boundary). Run pass = finish this pass. Play = run to convergence.
Graph input

Hypergraph JSON

JSON is optional — use Edit graph for direct editing. You can still paste a graph here. Cells need unique IDs; each net is a list of two or more cell IDs. You can also supply edges as two-item arrays or { source, target } objects; edge weights must be 1. An initialPartition is optional.

nodes: [{ id, label? }] · nets: [{ id?, cells: [id, …] }] · edges: [{ source, target }]

Two blocks are formed automatically. Larger graphs are supported, but the board is tuned for up to about 18 cells.
